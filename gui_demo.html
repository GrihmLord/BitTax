This prototype has been replaced.

The desktop UI now lives in renderer/index.html. Run it with npm run electron.

The dashboard that used to be here was retired rather than ported, because it:

  • carried a third copy of the 2024 tax brackets, and that copy was missing the 35% and 37% bands, so it under-reported tax above $243,725;
  • called CoinGecko on load, in a tool whose front page promises it runs offline;
  • presented "Pay $500 to IRS" and "Withdraw BTC" buttons that only decremented a variable — no payment and no transaction ever happened.

Rate tables now live once, in src/core/taxTables.js, with their source recorded. Network access is opt-in and off by default. The desktop app blocks outbound requests at the Electron session level.
