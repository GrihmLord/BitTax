This prototype has been replaced.

The desktop UI now lives in renderer/index.html and is loaded by main.js over a restricted app:// scheme. Run it with npm run electron.

The page that used to be here was retired rather than ported, because it:

  • built table rows with innerHTML from user-entered UTXO labels, and interpolated those labels into inline onblur handlers — a label of '); alert(1);// executed;
  • ran in a window with nodeIntegration: true and contextIsolation: false, so that injection reached Node;
  • carried its own copy of the cost-basis calculation, which had already drifted from the copy in src/services.

The calculation now lives once, in src/core, and is covered by npm test.
